# 🤖 ربات واچ‌لیست بورس تهران (TSETMC)

ربات تلگرامی واچ‌لیست بازار سرمایه ایران با داده‌های زنده **tsetmc.ir** و **کدال**.

## ✨ امکانات

- **واچ‌لیست تا ۱۵ نماد** با جستجوی هوشمند نام نماد (مثلاً «دامین»)
- **نرخ رشد بنیادی** از صورت‌های مالی کدال:
  - 📈 نسبت به سال گذشته (درآمد عملیاتی، سود ناخالص، سود عملیاتی، سود خالص، EPS)
  - 📉 نسبت به سه‌ماهه قبل (ربع به ربع، تفکیک دوره‌های تجمعی کدال)
- **وضعیت سهم**:
  - RSI روزانه (d) و هفتگی (w) — وایلدر ۱۴
  - قیمت پایانی / آخرین معامله / بازه روز
  - بیشترین و کمترین قیمت ماه، هفته و سال
  - پول هوشمند (ورودی/خروجی حقوقی در برابر حقیقی + ۵ روز اخیر)
  - درصد تغییر ماهیانه
  - سهامداران عمده (درصد + تغییرات)
  - عمق بازار ۵ سطح (خرید/فروش)
- **🆕 گزارش‌های جدید کدال** هر نماد (با دکمه دانلود PDF)
- **📢 اطلاعیه‌های ناظر بازار** هر نماد
- **🚨 هشدار خودکار** هر ۱۰ دقیقه در ساعات بازار (شنبه تا چهارشنبه ۸:۳۰–۱۲:۳۰)
  برای گزارش جدید کدال و اطلاعیه جدید ناظر بازار
- **🏁 گزارش پایانی** هر روز ساعت ۱۲:۴۰ (قیمت، تغییر، پول هوشمند، اخبار روز)
- **منوی تلگرام** (دکمه منو در نوار پیام): افزودن نماد / حذف نماد / واچ‌لیست من

## 🚀 اجرا (ویندوز)

```bat
1) دابل‌کلیک روی start.bat
2) توکن ربات را که از @BotFather گرفته‌اید وارد کنید
```

یا دستی:

```bat
venv\Scripts\activate
pip install -r requirements.txt
python bot.py TELEGRAM_TOKEN
```

## ⚙️ تنظیمات اختیاری

| متغیر محیطی | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات (به‌جای آرگومان خط فرمان) |
| `BOT_PROXY` | پراکسی (مثلاً `socks5://127.0.0.1:1080` یا `http://127.0.0.1:8080`) اگر دسترسی به api.telegram.org محدود است |

نمونه:

```bat
set BOT_PROXY=socks5://127.0.0.1:1080
python bot.py 123456:ABC-DEF...
```

## 💬 دستورهای ربات

| دستور | توضیح |
|---|---|
| `/start` | منوی اصلی |
| `/add` | ✚ اضافه کردن نماد به واچ لیست (نام نماد را بنویسید، مثل: دامین) |
| `/remove` | ─ حذف نماد از واچ ایست |
| `/mylist` | 🔳 واچ ایست من |
| `/alerts` | روشن/خاموش کردن هشدارها |
| `/cancel` | انصراف |

بعد از `/mylist`، روی نام هر نماد بزنید تا پنل نماد باز شود:
دکمه‌های «نرخ رشد سالانه»، «نرخ رشد سه‌ماهه»، «وضعیت سهم» (RSI روزانه/هفتگی،
قیمت پایانی، سقف‌وکف ماه و هفته، پول هوشمند، تغییر ماهیانه، سهامداران عمده،
عمق بازار ۵ سطح)، «گزارش‌های جدید» و «اطلاعیه ناظر بازار».

## 🗂 ساختار

```
tsetmc-bot/
├── bot.py          # هندلرها، منو، هشدارها، گزارش پایانی
├── tsetmc.py       # کلاینت API رسمی cdn.tsetmc.com
├── analytics.py    # RSI، پول هوشمند، پارس صورت‌های مالی و نرخ رشد
├── texts.py        # متن‌های فارسی پیام‌ها
├── storage.py      # ذخیره واچ‌لیست‌ها (data/*.json)
├── smoke_test.py   # تست داده با نمادهای واقعی
├── start.bat       # اجرای سریع روی ویندوز
└── requirements.txt
```

## 🧪 تست بدون تلگرام

```bat
venv\Scripts\activate
python smoke_test.py
```

## 📝 نکته‌ها

- همه‌ی داده‌ها مستقیم از APIهای رسمی `cdn.tsetmc.com` (همان که سایت جدید
  tsetmc.ir استفاده می‌کند) خوانده می‌شود؛ کلید API لازم نیست.
- اگر ساعت سیستم شما تغییر کند، زمان‌بندی هشدارها (ساعت تهران) تاثیر نمی‌پذیرد
  چون ربات از `Asia/Tehran` استفاده می‌کند.
- واچ‌لیست‌ها و وضعیت هشدارها در پوشه `data/` ذخیره می‌شوند؛ پاک‌کردن آن = ریست.
